### 💳 온라인 크레인 게임 "타이쿠레" CMS

#### 👤 조직
- 11명

#### 🛠️ 담당 업무
- 미들 개발자로서 CMS(Contents Management System) 사이트 유지보수
- NUXT 프론트의 jQuery 도입 철회, 자바스크립트, 타입스크립트의 모듈화 및 ES6 문법 도입, 바닐라 뷰와 NUXT 문법이 혼재되어있는 문제 등의 리팩토링
- 고객 요청 사항에 따른 새로운 기능, 배치의 개발
- 외부 API 도입 및 연계
- PHP, Laravel 버전업에 따른 견적작성
- 코드 리뷰
- 데이터 베이스 테이블 정의서, 배치 정의서 작성 및 검토

#### 🧑‍🔧 역할
- 프로젝트 리더

#### 🏆 성과·실적
- 트러블 없는 고객 요청 사항의 대처와 납기일에 따른 확실한 태스크 관리, 프로젝트 태스크 테크 리더로서 라라벨의 버전업 작업과 리팩토링, 정적분석 도입, 코드 스타일 수정 도구의 도입, 버그 수정에 따른 코드 리뷰를 담당하여 성공적으로 완료.

#### 🔧 사용 언어·환경
- NUXT
- Laravel
- Docker
- Zenkins
- MySql
- Google Spaner
