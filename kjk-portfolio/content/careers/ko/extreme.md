### 💳 온라인 크레인 게임 "타이쿠레" CMS

#### 👤 조직
- 11명

#### 🛠️ 담당 업무
- 미들 개발자로서 CMS(Contents Management System) 사이트 유지보수
- NUXT 프론트의 jQuery 도입 철회, 자바스크립트, 타입스크립트의 모듈화 및 ES6 문법 도입, 바닐라 뷰와 NUXT 문법이 혼재되어있는 문제 등의 리팩토링
- 고객 요청 사항에 따른 새로운 기능, 배치의 개발
- 외부 API 도입 및 연계
- PHP, Laravel 버전업에 따른 견적작성
- 코드 리뷰
- 데이터 베이스 테이블 정의서, 배치 정의서 작성 및 검토

#### 🧑‍🔧 역할
- 프로젝트 리더

#### 🏆 성과·실적
- 온라인 크레인 게임 CMS에서 풀스택 엔지니어로서 유지·운영 및 기능 개발을 담당하면서, 테크 리드로서 기술 개선을 주도해 왔습니다.
- 프론트엔드에서는 jQuery 의존성을 없애고 TypeScript 기반으로 전환하며 모듈화를 추진함으로써 코드 가독성과 유지보수성을 높이고, 개발 효율성 향상에 기여하고 있습니다.
- 백엔드에서는 Laravel의 버전업 및 리팩토링을 계획·실행하여 기술 부채를 해소하고 시스템 안정성을 향상시켰습니다.
- 또한 정적 분석 도구와 코드 포매터 도입, 코드 리뷰 추진을 통해 품질 기준을 표준화하고, 결함을 사전에 방지하며 리뷰 작업 시간을 절감하고 있습니다.
- 마지막으로 고객 요구에 기반한 기능 개발 및 외부 API 연계를 통해 서비스 가치를 높이고, 업무 관리와 기술 방침 조정을 수행함으로써 안정적인 프로젝트 진행과 납기 준수를 실현해 왔습니다.

#### 🔧 사용 언어·환경
- NUXT
- Laravel
- Docker
- Zenkins
- MySql
- Google Spaner

### 💳 타워레코드 오프라인 매장용 추첨 앱 추가 개발 및 유지보수

#### 👤 조직
- 5명

#### 🗓️ 기간
- 2025년 12월 ～ 2026년 2월

#### 🛠️ 담당 업무
- 신규 요구사항인 '100연속 뽑기(가챠)' 기능의 핵심 비즈니스 로직 설계 및 화면 연동 작업 수행.

- 최신 운영체제(윈도우 11) 도입에 따른 기존 앱 호환성 점검 및 레거시 시스템 개선 진행.

- 다중 단말기 연결 시 발생하는 네트워크 병목 현상 및 연결 초과 오류 원인 분석과 디버깅 완료.

- 기기 초기 설정(키팅) 절차 간소화 및 설치 매뉴얼 최신화 적용.

#### 🧑‍🔧 역할
- 메인 프로그래머

#### 🏆 성과·실적
- 오프라인 매장용 추첨 앱에서 ‘100연속 가챠’ 기능 구현을 중심으로 비즈니스 로직 설계부터 화면 연동까지 일관되게 담당해 왔습니다.
- 기존 경품 등록 상한을 10건에서 100건으로 확대함으로써 대규모 이벤트 대응력을 높이고, 운영 유연성 확대에 기여하고 있습니다.
- 또한, 다중 단말기 연결 시 발생하던 네트워크 오류의 원인 분석 및 개선을 수행해 시스템의 안정적인 가동을 구현함으로써 현장 운영의 신뢰성 향상에 기여했습니다.
- Windows 11 환경 대응 및 레거시 시스템 개선을 통해 호환성 문제를 해소하고, 운영 위험 감소를 실현하고 있습니다.
- 또한 환경 구축 절차를 간소화하고 설치 프로세스를 최적화함으로써 도입 작업 시간을 단축하고 운영 비용 절감에도 기여했습니다.

#### 🔧 사용 언어·환경
- 개발 언어 및 구조: C# 기반의 N-tier 아키텍처 적용
- 빌드 및 배포: 개별 프로젝트 빌드 후 독립 실행 파일(EXE) 형태로 납품
- 실행 환경: 윈도우 11 운영체제
- 프로젝트 관리: 레드마인(Redmine) 도구 활용
