# 📌 Summary
- React를 Next.js로 마이그레이션하여 서버 사이드 렌더링을 통해 검색 엔진 최적화
- History API를 활용하여 모달의 뒤로가기 구현
> - 주요 기능: 자기소개, 인적 사항, 기술 스택, GitHub 링크, 프로젝트 경험, 업무 경력

# 🤔 Background
첫 개발을 PHP로 시작했지만, 최근에는 프론트엔드와 백엔드 개발자의 구분이 점점 희미해지며, 업무에서도 프론트엔드, 백엔드, 인프라를 가리지 않고 다양한 분야를 담당하는 경우가 많아졌다. 
이로 인해 개발 지식을 매번 검색하거나 단순히 기록으로 남기는 것에 한계를 느끼게 되어, 이를 보완하기 위해 직접 프로젝트를 제작해 남기기로 했다.

# 🔍 Meaning
업무상 바닐라 뷰, 블레이드, 블레이저와 같은 프론트엔드 기술을 접한 경험은 꽤 있었지만, Nuxt는 현재 프로젝트에서 처음 다루는 프레임워크였다. 이러한 경험을 바탕으로 Nuxt로 포트폴리오 웹페이지 프로젝트를 제작하기로 결정했다.
처음부터 직접 프론트를 개발하고 설계하는 것은 처음이지만, 이를 통해 Nuxt.js에 대한 이해도를 크게 높일 수 있었다. 또한 프론트엔드 개발의 전반적인 흐름을 파악하며, 개발 기간을 보다 정확하게 산정하는 데도 도움이 되었다.

# 🔨 Technology Stack(s)
Nuxt.js, tailwindcss, Vercel, TypeScript, JavaScript
