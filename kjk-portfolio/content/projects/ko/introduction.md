# 📌 Summary
- Nuxt.js를 활용한 웹사이트. 자기소개, 다국어, 검색 엔진 최적화 기능 사용
- Nuxt에서 지원하는 공식 모듈을 최대한 활용
> - 주요 기능: 자기소개, 인적 사항, 기술, GitHub 링크, 프로젝트 경험, 업무 경력

# 🤔 Background
워드, 엑셀, PDF 등 다양한 형식으로 직무경력서를 만들어 본 경험은 수없이 많지만, 웹 개발자라면 역시 "나만의 포트폴리오"를 직접 웹사이트 형태로 제작하는 것이 가장 좋은 경험이자 강력한 어필 수단이라고 생각했다. 
이 웹페이지에는 내가 일본에서 어떤 개발자로서의 길을 걷고 있는지 보여주기 위해 최대한 많은 내용을 담으려 노력했다.

# 🔍 Meaning
업무상 바닐라 뷰, 블레이드, 블레이저와 같은 프론트엔드 기술을 접한 경험은 꽤 있었지만, Nuxt는 현재 프로젝트에서 처음 다루는 프레임워크였다. 이러한 경험을 바탕으로 Nuxt로 포트폴리오 웹페이지 프로젝트를 제작하기로 결정했다.
처음부터 직접 프론트를 개발하고 설계하는 것은 처음이지만, 이를 통해 Nuxt.js에 대한 이해도를 크게 높일 수 있었다. 또한 프론트엔드 개발의 전반적인 흐름을 파악하며, 개발 기간을 보다 정확하게 산정하는 데도 도움이 되었다.

# 🔨 Technology Stack(s)
Nuxt.js, tailwindcss, Vercel, TypeScript, JavaScript
