# 📌 概要
- Nuxt.jsを活用したウェブサイト。自己紹介、複数言語対応、検索エンジン最適化機能を使用。
- Nuxtが提供する公式モジュールをできるだけ活用する予定。
> - 主な機能: 自己紹介、基本情報、技術、GitHubリンク、プロジェクト経験、職務経歴

# 🤔 背景
Word、Excel、PDFなど、様々な形式で職務経歴書を作成した経験は数え切れないほどありますが、やはりWeb開発者であれば「自分のポートフォリオサイト」を作ることが、最も良い経験であり、強力なアピールになると思った。
このWebページには、私が日本でどのような開発者としての道を歩んでいるのかを伝えるために、できる限り多くの内容を詰め込むようにした。  

# 🔍 意義
業務ではバニラVueやBlade、Blazorなどのフロントエンド技術に触れる機会が多くありましたが、Nuxtは現在のプロジェクトで初めて扱うフレームワークでした。  
この経験を生かし、Nuxtでポートフォリオウェブサイトを作成することに決めました。  
初めてフロントエンドの設計・開発を一から行ったことで、Nuxt.jsに対する理解が大きく深まりました。  
また、フロントエンド開発の全体的な流れを把握し、より正確に開発期間を見積もる経験にもつながりました。  

# 🔨 技術スタック
- Nuxt.js
- TailwindCSS
- Vercel
- TypeScript
- JavaScript

# ⚙️ セットアップと使用方法
```
# Install JavaScript Packages
pnpm install

# Run Frontend Server
pnpm run dev
```
