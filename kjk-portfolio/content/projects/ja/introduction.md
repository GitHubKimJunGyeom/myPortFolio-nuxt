# 📌 概要
- ReactをNext.jsに移行し、サーバーサイドレンダリングを通じてSEO対策を実施
- History APIを活用したモーダルの戻る機能を実装
> - 主な機能: 自己紹介、基本情報、技術スタック、GitHubリンク、プロジェクト経験、職務経歴

# 🤔 背景
最初はPHPで開発を始めましたが、最近ではフロントエンドとバックエンドの区別が曖昧になり、業務でもフロントエンド、バックエンド、インフラを問わず多様な分野を担当することが多くなりました。  
そのため、開発知識を都度検索したり、単に記録として残すだけでは限界を感じ、これを補完するために直接プロジェクトを制作し、知識を蓄積することにしました。  

# 🔍 意義
業務ではバニラVueやBlade、Blazorなどのフロントエンド技術に触れる機会が多くありましたが、Nuxtは現在のプロジェクトで初めて扱うフレームワークでした。  
この経験を生かし、Nuxtでポートフォリオウェブサイトを作成することに決めました。  
初めてフロントエンドの設計・開発を一から行ったことで、Nuxt.jsに対する理解が大きく深まりました。  
また、フロントエンド開発の全体的な流れを把握し、より正確に開発期間を見積もる経験にもつながりました。  

# 🔨 技術スタック
- Nuxt.js
- TailwindCSS
- Vercel
- TypeScript
- JavaScript

# ⚙️ セットアップと使用方法
```
# Install JavaScript Packages
pnpm install

# Run Frontend Server
pnpm run dev
```
